Sierpinski Carpet implementation using WebGL.

Basic server.py added for visualization.

### V1
Implements the carpet with fixed color/depth
### V2
Adds sliders to customize recursion depth and color
### V3
Uses a homogeneous transformation matrix inside the vertex shader that can change the location of the carpet.
